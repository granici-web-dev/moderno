## About

Moderno is a pixel-perfect implementation of a design mockup into a fully responsive website. The project demonstrates clean markup, structured CSS, and an automated build pipeline using Gulp.

## Features

- **Responsive Design** — adapts seamlessly to desktop, tablet, and mobile screens
- **Semantic HTML5** — accessible and SEO-friendly markup structure
- **Custom CSS3** — hand-written styles with Flexbox/Grid layouts, no CSS frameworks
- **Gulp Build Pipeline** — automated workflow for development and production builds
- **Cross-Browser Compatible** — tested across modern browsers

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic page structure |
| CSS3 | Styling, Flexbox/Grid layouts, responsive design |
| JavaScript | Interactive elements |
| Gulp | Task runner — build automation, live reload |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/granici-web-dev/moderno.git

# Navigate to project
cd moderno

# Install dependencies
npm install

# Run development server
gulp
```
